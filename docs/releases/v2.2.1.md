# Release v2.2.1

- Date (UTC): 2026-09-19
- Previous tag: v2.2.0
- Channel: stable
- Stage: stable

## Highlights

- 站长状态卡：从原内联实现拆分出独立的 `OwnerStatusCard` 组件，弹层与移动端导航共用同一份渲染逻辑；新增游戏卡片与音乐卡片，支持封面、播放进度条、均衡器动画与黑胶唱片转场
- 站长状态协议扩展：上报数据新增 `category` 与 `game` 元数据字段，服务端做长度截断、`http(s)` 协议校验与分类白名单清洗
- 新增 `/public/game-lookup` 接口：按名称查询 Steam 商店元数据，正负结果均写入 Redis 缓存（命中 24h / 未命中 1h），并按 IP 维度限流
- 新增 `grtblog` CLI，用于内容与站点管理
