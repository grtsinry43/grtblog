# Release v2.2.2

- Date (UTC): 2026-11-15
- Previous tag: v2.2.1
- Channel: stable
- Stage: stable

## Highlights

- 新增阅读设置：支持小、中、大三档正文字号及无衬线、衬线字体切换，偏好保存在当前浏览器，并在首屏加载时应用
- 文章阅读进度自动保存在当前浏览器，再次打开时可通过提示继续上次阅读
- 文章选中文字后可直接引用到评论，或复制附带文章标题与链接的摘录
- 调整浮动窗口交互：支持桌面端拖动缩放、放大还原与最小化动效，优化移动端面板与内容滚动
- 统一页面标题、侧栏、时间线与基础组件的排版和视觉样式，补充键盘焦点提示与减少动态效果支持
- 更新服务端、CLI、管理后台、前台及文档站依赖，包括 markdown-it、undici、ExifReader 和 Storybook
